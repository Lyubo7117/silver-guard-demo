# 银发守护 · 概念演示原型

基于多模态大模型的城市公共空间适老化智能感知与服务系统 —— **概念演示原型（Concept Demo）**。

> 第十二届中国研究生智慧城市技术与创意设计大赛 · 创意设计赛 · 智慧生活与大健康赛道
> 团队：晚晴智守（刘宇博 / 尚金凌 / 张烨）

## 这是什么

本项目目前处于**方案设计 + 原型验证**阶段，尚无真实硬件与自采数据集。
本原型用于向评委与相关方直观展示系统的**形态、架构与"感知-理解-服务"闭环**，
页面中所有节点状态、事件、图表均为**模拟数据**，不代表真实运行结果。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run Home.py
```

## 页面结构

| 页面 | 内容 |
| --- | --- |
| Home（系统概览） | 项目定位、四层架构、核心指标（设计目标值）、系统闭环 |
| 1 实时监测看板 | 多节点状态卡片、模拟主监测视图（检测框）、SOS 本地快速告警 |
| 2 事件与处置 | 异常事件列表、事件时间线、云端 LLM 服务建议、处置流转 |
| 3 小程序三端 | 「银发守护」老人端 / 家属端 / 管理者端界面原型 |
| 4 管理者看板 | 适老化指数、事件趋势、类型分布、各节点事件、响应时长 |
| 5 技术验证路线 | 关键技术"设计目标 vs 当前状态"对照、无硬件替代方案、12个月路线 |
| 6 指标预估依据 | 核心设计指标的预估推导链条与公开基准来源（预估值，非实测） |

## 部署到 Streamlit Cloud

完整步骤见 [DEPLOY.md](DEPLOY.md)。概要：
1. 本目录已初始化为 git 仓库并完成首次提交，推送到你的 GitHub 仓库；
2. 在 [Streamlit Cloud](https://share.streamlit.io) 新建 App，选择该仓库，主入口设为 `Home.py`；
3. 依赖自动读取 `requirements.txt`，构建完成后得到在线链接。

## 关键说明

- 技术指标（mAP≥90%、延迟<200ms、12类异常、准确率92%）当前为**设计目标值**，
  实测进展与验证方式见「5 技术验证路线」页；各指标的**预估依据**（公开基准推导链条）见「6 指标预估依据」页。
- 隐私机制：边缘端本地人脸脱敏、仅上传行为特征向量、云端 AES-256 加密。
